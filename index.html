How to use Match Notes

Track the match as it happens, review key decisions, and export a clean log when you are finished.

1

Run the clock

Use the play/pause button or press the space bar. You can update the clock time, move to the next period, or end the match from the top controls.

2

Log events when they happen

Click an event button right away. The app saves the timestamp from the moment you clicked the event, even if you fill out the details a few seconds later.

3

Adjust the timestamp if needed

Inside each event window, use the 5-second or 15-second rewind buttons to fine-tune the time before saving. The timestamp can also be manually changed there.

4

Mark decisions clearly

Use the Incorrect toggle when the decision was wrong. Those events will get an “incorrect decision” tag and count in the stats.

Logging discipline: If a foul or missed foul also involves a caution, send-off, missed caution, or missed send-off, log it through the discipline event and add the details there. Penalties and missed penalties should still be logged as penalty events.
